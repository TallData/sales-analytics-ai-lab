# Project standard

Each example must include:

1. Business question, intended user, and decision supported.
2. Data sources, synthetic fixtures, definitions, and input limitations.
3. Runnable setup instructions, dependencies, and cost assumptions when implemented.
4. Architecture and explanation of where deterministic code and AI are used.
5. Sample output with citations or traceable calculations.
6. Meaningful evaluation against a fixed manual baseline and failure cases.
7. Human review boundaries and known limitations.
8. Maturity status and reproducible results, clearly separated from targets.

Never commit credentials, private customer records, or employer-confidential material. Use synthetic data for account and application examples. Record human review time when calculating efficiency. A passing demo is not evidence of production readiness.
