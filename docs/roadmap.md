# Initial roadmap

## Foundation

- Confirm shared metric definitions and synthetic data contracts.
- Create a common project template and evaluation record.
- Establish issue, branch, PR, review, and merge workflow.

## First implementations

1. Monthly Sales Performance Analyst: validated monthly KPIs and a sourced narrative.
2. Application Assignment: deterministic matching and an exception-review queue.
3. Account Expansion Radar: account evidence and reviewable growth hypotheses.
4. Market Signals and Audience Connection: use Gridbrief as the public reference; implement source verification, audience mapping, and reviewable briefs before publishing integration.

## Release gate

Each example needs a reproducible run, documented failure cases, meaningful evaluation, and measured human effort before being described as evaluated. Keep existing external projects linked until their source and reuse conditions are reviewed. Do not merge implementation PRs automatically.
